## 개요

**DFS(깊이 우선 탐색)**는 그래프나 트리를 탐색하는 기본적인 알고리즘입니다.

### DFS의 특징
- 스택(Stack)을 기반으로 하는 탐색 알고리즘
- 한 경로를 끝까지 탐색한 후 다른 경로를 탐색합니다
- 재귀 또는 명시적 스택 자료구조로 구현 가능
- 시간복잡도: O(V + E) (V: 정점, E: 간선)
- 공간복잡도: O(V)

### DFS의 동작 원리

1. 시작 노드를 방문합니다
2. 현재 노드의 인접한 미방문 노드를 스택에 추가합니다
3. 스택이 비워질 때까지 2-3을 반복합니다
4. 더 이상 탐색할 노드가 없으면 백트래킹합니다

## 포함된 문제

### 1️⃣ 그래프 방문 순서 출력
주어진 그래프에서 DFS를 이용하여 모든 노드를 방문 순서대로 출력합니다.
- **개념**: 기본적인 DFS 구현
- **난이도**: ⭐ 쉬움

### 2️⃣ 연결 요소의 개수 구하기
그래프의 연결 요소(Connected Component) 개수를 구합니다.
- **개념**: 여러 번의 DFS 호출
- **난이도**: ⭐ 쉬움

### 3️⃣ 경로 찾기
두 정점 사이의 경로가 존재하는지 판단하고 경로를 찾습니다.
- **개념**: DFS를 이용한 경로 추적
- **난이도**: ⭐⭐ 중간

### 4️⃣ 사이클 찾기
방향 그래프에서 사이클이 존재하는지 판단합니다.
- **개념**: 노드의 상태를 관리하며 DFS 수행
- **난이도**: ⭐⭐ 중간

### 5️⃣ 이진 트리 경로의 합
루트에서 리프까지의 경로 중 합이 특정 값과 같은 경로의 개수를 구합니다.
- **개념**: 트리에서의 DFS와 백트래킹
- **난이도**: ⭐⭐ 중간

### 6️⃣ 미로 탈출
2D 미로에서 시작점에서 목표점까지의 경로를 찾습니다.
- **개념**: 2D 배열에서의 DFS
- **난이도**: ⭐⭐⭐ 어려움

## 핵심 개념

### DFS vs BFS

| 구분 | DFS | BFS |
|------|-----|-----|
| 자료구조 | 스택(Stack) | 큐(Queue) |
| 탐색 방식 | 깊이 우선 | 너비 우선 |
| 메모리 | 적음 | 많음 |
| 경로 찾기 | ⭕ 좋음 | ⭕ 좋음 |
| 최단 경로 | ⚠️ 가중치 없을 때만 | ⭕ 최적 |

### DFS 적용 분야

- **그래프 문제**
  - 연결성 판단
  - 연결 요소 찾기
  - 사이클 감지
  - 위상 정렬

- **트리 문제**
  - 경로 찾기
  - 경로의 합 계산
  - 트리 순회

- **조합/순열 문제**
  - 백트래킹
  - 부분집합
  - 순열/조합 생성

- **게임/AI**
  - 미로 탈출
  - 게임 트리 탐색
